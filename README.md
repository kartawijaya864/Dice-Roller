# Dice Roller

Aplikasi Android sederhana yang dibuat menggunakan Kotlin dan Jetpack Compose untuk mensimulasikan pelemparan dadu.

## Features

* Roll Dice dengan satu tombol
* Menampilkan hasil angka dadu secara acak
* Menggunakan Jetpack Compose
* User Interface sederhana dan mudah digunakan

## Technologies Used

* Kotlin
* Android Studio
* Jetpack Compose
* Material Design 3

## How to Run

1. Clone repository ini.
2. Buka project menggunakan Android Studio.
3. Tunggu proses Gradle Sync selesai.
4. Jalankan aplikasi pada emulator atau perangkat Android.
5. Tekan tombol **Roll** untuk melempar dadu.
